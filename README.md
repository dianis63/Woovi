# Woovi 🌙

**Aplicación móvil Android en desarrollo.**

Woovi es un proyecto personal desarrollado para Android, utilizando Kotlin y Jetpack Compose. Integra Supabase para los servicios de autenticación y gestión de datos, junto con Ktor para la comunicación con servicios externos.

## 🛠️ Tecnologías

- Kotlin
- Jetpack Compose
- Supabase
- Ktor
- Android Studio
- Gradle

## ✨ Funcionalidades

- Autenticación de usuarios.
- Gestión de sesiones.
- Navegación entre pantallas.
- Gestión de perfiles.
- Estructura modular y componentes reutilizables.

*El proyecto se encuentra actualmente en desarrollo.*

## 🚀 Instalación

1. Clona el repositorio:

   ```bash
   git clone https://github.com/dianis63/Woovi.git
   ```

2. Abre el proyecto en Android Studio.
3. Configura las credenciales necesarias de Supabase en tu entorno local.
4. Sincroniza Gradle.
5. Ejecuta la aplicación en un emulador o dispositivo Android.
